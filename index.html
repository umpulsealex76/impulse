Защита данных

IMPULSE 8.0 · Резервные копии с паролем. Все действия выполняются на телефоне, без сервера.

Перед копированием: проверь, что в этой версии видны нужные записи и настройки. В разных файлах Chrome может хранить разные данные. Никакие старые HTML-файлы не удаляются.

🔒 Создать резервную копию

Сохраняет уже записанные данные: клиентов, расписание, длительности, прайс-лист и название бизнеса. Пароль нужен для открытия копии.

Файл обычно появится в «Мои файлы → Загрузки». Пароль нигде не сохраняется — без него копию не восстановить.

🔓 Восстановить из копии

Выбери ранее созданный зашифрованный файл и введи пароль. Перед заменой текущих данных приложение попросит подтверждение.

Защищённый файл содержит только данные. Он не скрывает код самого HTML-приложения. Для настоящих клиентов потребуется отдельная проверка безопасности.
